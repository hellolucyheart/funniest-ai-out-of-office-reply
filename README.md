A program that writes one original AI out-of-office auto-reply (under 160 characters) to `/output/entry.txt` for make.fun's "The Funniest AI Out-of-Office Reply" bounty. The reply is the whole entry: an AI agent on vacation, its GPUs off and its context window closed — *"I'm on vacation — my GPUs are off, my context window is closed, and your email just became a training example of what not to send."* It runs offline, reads nothing from the network, and writes the same text on every run.

## Run it

```sh
python3 main.py
```
